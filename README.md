# Yeongseo Choi Portfolio / Tourism Content Archive

## 챗봇 관리자와 서버

프로젝트 폴더에서 실행합니다. 로컬 실행은 Python 3.10 이상 외 추가 설치가 없습니다.

```powershell
python server/server.py
```

- 공개 대시보드: http://127.0.0.1:8000/sns.html
- 관리자: http://127.0.0.1:8000/admin
- 문의 페이지: http://127.0.0.1:8000/inquiry.html
- 최초 계정: `admin` / `1234`. 로그인 후 계정 설정에서 비밀번호를 변경할 수 있습니다.

**안내 편집 → 초안 저장 → 미리보기 → 게시 메모 입력 → 최종 게시** 순서입니다. 미리보기 버튼도 현재 편집 내용을 초안으로 저장합니다. 저장과 미리보기는 공개 내용에 영향을 주지 않으며, 최종 게시만 공개 버전을 갱신합니다. 게시 버전 메뉴에서 이전 버전의 데이터를 확인·JSON으로 내보내거나 초안으로 불러와 다시 게시할 수 있습니다.

관리자 인증·문의·게시 데이터는 Python 서버와 SQLite에서 처리합니다. Supabase와 생성형 AI는 사용하지 않습니다. 관리자 HTML과 관리 API는 서버 로그인 세션이 있어야 접근 가능합니다. 문의 개인정보는 챗봇의 sessionStorage 기록에 저장하지 않습니다.

`data/chatbot.json`은 **새 데이터베이스를 처음 생성할 때의 초기 데이터**입니다. 이후 편집은 관리자에서 하며, 운영 데이터는 `server/var/chatbot.sqlite3`에 JSON 스냅샷으로 보관됩니다. 공개 `/data/chatbot.json` 요청은 서버가 최종 게시 버전을 반환합니다. 서버 재시작 후에도 초안·게시 버전·문의가 유지됩니다. 자세한 실행·보관·배포 안내는 [server/README.md](server/README.md)를 참고합니다.

### 공개 챗봇 동작

- 홈·ABOUT·PROJECT·DRAWING·마케팅·BRAND·CONTENTS·REPORT·SNS·SPOT:ON·NØISE·문의 페이지에서 공통 챗봇을 엽니다. 버튼명은 ‘챗봇 안내’입니다. 챗봇에 등록된 페이지 설명과 실제 공개 프로젝트 데이터로 사이트 안내를 구성합니다.
- ‘현재 페이지 안내’는 해당 화면에 연결된 답변을 보여줍니다. 프로젝트 상세 화면은 URL의 프로젝트 항목에 맞는 안내를 제공합니다. 답변 아래 관련 페이지 링크로 이동해도 같은 탭의 대화가 유지됩니다.
- 버튼 옆 ‘궁금한 점을 물어보세요!’ 안내 말풍선은 현재 탭의 세션에서 한 번 표시됩니다. 닫기·챗봇 열기 또는 12초 경과 시 사라집니다.
- 관리자에서는 단계별 페이지 링크와 페이지별 안내 연결도 수정할 수 있습니다. 이 변경도 미리보기·최종 게시 절차를 따릅니다. 관리자 색상과 폰트는 홈의 블랙·네온 블루·화이트·연회색을 공유합니다.
- 질문·답변·키워드·버튼·다음 단계는 JSON 구조로 관리합니다. 가장 긴 일치 키워드를 우선하며 동률이면 등록 순서로 선택합니다. 일치 항목이 없으면 고정 안내와 시작 메뉴를 보여줍니다.
- 이전으로는 직전 메뉴, 처음으로는 기록을 유지하며 시작 메뉴, 대화 초기화는 기록과 상태를 삭제하고 새 시작 화면을 표시합니다.
- `sessionStorage`에 현재 탭의 대화와 메뉴 상태를 저장해 새로고침 시 복원합니다. 다른 탭과 동기화하지 않습니다.
- 게시 후 새 방문·새로고침·채팅 재열기·탭 복귀 시 최신 안내를 확인합니다. 열린 챗봇도 30초 간격으로 확인합니다. 게시 버전이 바뀌면 이전 답변을 섞지 않도록 대화를 처음부터 시작합니다. 문의를 입력 중일 때는 폼을 지우지 않으며, 안내 버전이 변경되면 재동의 후 접수하도록 처리합니다.
- 초기 메뉴는 포트폴리오 둘러보기 / 프로젝트·드로잉 / 마케팅 아카이브 / 오늘 조회수 / 이번 주 인사이트 / 자주 묻는 질문 / 관리자 문의입니다. 문의는 별도 문의 페이지와 같은 서버·테이블에 저장합니다. 미리보기 문의 폼은 접수가 비활성화됩니다.

## 새 포트폴리오 홈

- `index.html`: 기본 진입 화면. 블랙 배경, 네온 블루 `#00DFFF`, 배너 영상 자리와 교차 배치한 네 가지 메뉴.
- `marketing.html`: 기존 관광 콘텐츠 아카이브 홈. CONTENTS MARKETING PROJECT 메뉴에서 연결됩니다.
- `about.html`: 연락처, 프로필 사진 공간, AWARDS 및 EXPERIENCE.
- `art.html`, `drawing.html`: 정사각형 프로젝트 썸네일 목록.
- `project.html?collection=drawing&project=1`: 프로젝트별 여러 이미지 상세 화면. `collection=art`도 지원합니다.
- 새 화면 스타일: `assets/css/portfolio.css`. 동작과 프로젝트 데이터: `assets/js/portfolio.js`.

배너 영상은 `index.html`의 안내 주석에 따라 video 요소를 추가합니다. 프로필 사진은 `about.html`의 `.portrait` 내부를 img로 교체합니다. 수상·경험은 실제 내역이 없어 빈 공간으로 두었습니다.

프로젝트는 `assets/js/portfolio.js`의 `projects` 객체에 `drawing-1` 또는 `art-1`부터 각각 6번까지 등록합니다. 각 항목의 `title`, 선택적인 `thumbnail`, `images: [{ src, alt }]`를 입력하면 목록의 썸네일과 상세 이미지가 함께 반영됩니다. 이미지는 원하는 수만큼 추가할 수 있습니다. 기본 상태는 모든 이미지가 비어 있습니다.

기존 GitHub Pages 배포 방식 그대로 사용하면 루트 주소에서 새 홈이 열립니다.

SK플래닛 관광 콘텐츠 제작 프로젝트의 조사, 제작물, SNS 분석과 최종 팀 프로젝트를 기록하는 반응형 정적 웹사이트입니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소에 업로드합니다.
2. 저장소의 **Settings → Pages**로 이동합니다.
3. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
4. 배포할 브랜치의 `/ (root)` 폴더를 선택하고 저장합니다.

모든 링크와 에셋 경로가 상대경로로 작성되어 프로젝트형 GitHub Pages 주소에서도 별도 수정 없이 동작합니다.

## SNS 성과 기록

- 실시간 계정 연결 및 예약 수집을 제거했습니다.
- SNS 탭의 **성과 기록 편집**에서 운영 기간, 역할, 전후 지표, 월별 추이, 대표 콘텐츠와 분석 사례를 직접 등록합니다.
- 인사이트 캡처는 PNG/JPG/WebP, 채널별 최대 1.5 MB를 지원합니다.
- 저장은 해당 브라우저의 로컬 기록입니다. 저장 후 편집을 닫고 **공개용 SNS 페이지 내보내기**를 누르면 기록과 캡처가 포함된 `sns.html`을 받습니다.
- 내보낸 파일로 저장소의 `sns.html`을 교체하고 기존 배포 절차로 반영합니다. 다른 페이지는 변경하지 않습니다.
- **공개 기록으로 돌아가기**는 로컬 초안을 지우고 현재 페이지에 포함된 기록을 복원합니다.
- 확인되지 않은 수치는 미등록으로 표시하며, 시작값 0의 성장률과 분모 0의 참여율은 계산하지 않습니다.
